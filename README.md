# HopeChestCore

Fortnite-Truhenzähler für Windows. HopeChestCore wertet lokal gespeicherte Replays nach dem Match aus und zeigt eigene Truhen, Teammate-Truhen und die Gesamtsumme.

## Download

[Windows-ZIP v0.4.0 herunterladen](https://github.com/AsheraNo/HopeChestCore/releases/download/v0.4.0/HopeChestCore_v0.4.0.zip) · [Alle Releases](https://github.com/AsheraNo/HopeChestCore/releases)

1. Für Windows x64 die [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) installieren, falls sie fehlt.
2. Die ZIP vollständig entpacken und `HopeChestCore.exe` starten.
3. Die Replay-Aufzeichnung in Fortnite aktivieren. HopeChestCore importiert abgeschlossene Matches automatisch und speichert die Statistik lokal.

Der C#-Quellcode und die Lizenztexte liegen im Ordner `Quellcode` der Windows-ZIP.
